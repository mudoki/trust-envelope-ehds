# Trust Envelope instantiations - EHDS secondary use

Companion material for *Trusted Data Exchanges Across Regulatory Boundaries: A
Research Agenda for Personal Data Vault Interoperability*, 21st IFIP Summer
School on Privacy and Identity Management, Leuven, 2026.

`envelope-secondary-use.ttl` instantiates the envelope described in Section 5.3:
a research institution receives glucose data from a personal data vault under a
data permit issued by a Health Data Access Body (EHDS Art. 68).

The properties `te:request` and `te:stage` are proposed extensions to the Trust
Envelope model.

Vocabulary alignment is provisional pending review.
